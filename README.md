# Not Our Game: Love the Game, Respect Everyone

A campaign to prevent domestic and family violence on State of Origin nights.

Built by students at Swinburne University of Technology for ART20003 (Skills and Strategies for Social Change). Not affiliated with the NRL, any club or any broadcaster. This is not a crisis service: in an emergency, call 000. For support, call 1800RESPECT on 1800 737 732.

This folder is generated; edit the copy in the project's `site-src/content.py` and rebuild.
